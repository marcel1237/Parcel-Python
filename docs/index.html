🐍 Parcel-Python

Toolkit de Desenvolvimento Industrial Baseado em IA & PyQt6

1. Introdução ao Software

O Parcel-Python é um Ambiente de Desenvolvimento Integrado (IDE) avançado e Toolkit Industrial desenvolvido em Python 3.10+ com PyQt6. Ele integra inteligência artificial on-device (SS AI Agent), versionamento incremental em SQLite (.parcel_backups.db), designer visual QML interativo e realce de sintaxe profissional para mais de 15 linguagens.

2. Instalação & Execução Rápida

Utilize os scripts de automação fornecidos na raiz do projeto para configurar o ambiente virtual e rodar a IDE:

# 1. Configurar dependências e ambiente virtual
./build.sh

# 2. Iniciar a IDE
./run.sh

Ou manualmente via terminal:

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 -m parcel.main

3. Navegação & Telas Iniciais

  • Dashboard: Tela de boas-vindas com acesso rápido para criar novos projetos ou abrir projetos existentes.
  • New Project Wizard: Assistente estruturado em etapas (Projeto, Linguagem, Framework, Dependências, Git e Sumário).
  • Open Project Analyzer: Seleciona pastas de projeto e realiza análises estáticas (detecção de Git, contagem de arquivos, tamanho e build systems).
  • Settings: Configuração segura de chave de API do Gemini (com criptografia local) e monitoramento de APIs integradas.

4. Workspace & Botões de Ação do Cabeçalho

Ao abrir um projeto, o Workspace exibe o cabeçalho superior contendo os botões de controle industrial:

  • ✨ East Pane Alterna o painel de assistentes de IA à direita (Gemini, OpenAI, Shell Scripting e Git).
  • 🌐 South Pane Alterna o painel inferior contendo navegadores web (Google, Duck.ai, ChatGPT), Terminal, Logs, Problemas e Banco de Dados.
  • 🎨 Designer Abre o QML Visual Designer com canvas interativo.
  • 🔨 Build + Backup Executa backup incremental em SQLite (`.parcel_backups.db`) e compila/verifica a sintaxe do projeto em tempo real no Terminal.
  • 📦 Export Abre o menu de exportação nativa para pacotes Debian (`.deb`), Archives (`.tar.gz`) e estruturas AppImage (`.AppDir`).

5. QML Visual Designer & Canvas Interativo

O designer visual permite arrastar e posicionar componentes QML/Kirigami diretamente com o mouse no canvas:

  • Paleta QML: Mais de 30 componentes disponíveis (Botões, Inputs, Sliders, Containers, Listas, Diálogos).
  • Canvas Drag-and-Drop: Clique e arraste qualquer componente para definir suas coordenadas X e Y visualmente.
  • Inspetor de Propriedades: Atualização instantânea de IDs, textos, cores e dimensões.
  • Gerador QML: Código QML gerado e atualizado ao vivo conforme você interage com o design.

6. Syntax Highlighter Profissional

O editor de código suporta realce de sintaxe avançado para: Python, C/C++, Java, C#, VB.NET, F#, Go, Rust, JavaScript, TypeScript, PHP, Ruby, Perl, Raku, ASP, JSP, Assembly, Shell Script, SQL, JSON, YAML, HTML/XML/QML e Markdown.
